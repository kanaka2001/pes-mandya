## 🏛️ The AWS Well-Architected Framework

A set of best practices for designing and operating reliable, secure, efficient, and cost-effective systems in the cloud.

| Pillar | Focus | Example question |
|---|---|---|
| ⚙️ **Operational Excellence** | Run and monitor systems, improve continuously | How do you detect and respond to issues? |
| 🔐 **Security** | Protect data, systems, and assets | Who can access what? |
| 🔁 **Reliability** | Recover from failure and meet demand | What happens if one AZ goes down? |
| 🚄 **Performance Efficiency** | Use resources efficiently as needs change | Are you using the right instance type? |
| 💰 **Cost Optimization** | Avoid unnecessary spend | Are you paying for idle resources? |
| 🌱 **Sustainability** | Minimize environmental impact | Can you reduce resource usage? |
