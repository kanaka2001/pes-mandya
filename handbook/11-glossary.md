# Chapter 11 — Glossary

> Quick reference for terms used in this handbook.

---

| Term | Definition |
|---|---|
| **AZ** | Availability Zone, an isolated location within a Region |
| **AMI** | Amazon Machine Image, a template for launching instances |
| **CIDR** | Notation for IP ranges, such as `10.0.0.0/16` |
| **EC2** | Elastic Compute Cloud, virtual servers |
| **IAM** | Identity and Access Management |
| **IGW** | Internet Gateway |
| **NACL** | Network Access Control List, a stateless subnet firewall |
| **RBAC** | Role-Based Access Control |
| **S3** | Simple Storage Service, object storage |
| **VPC** | Virtual Private Cloud |
